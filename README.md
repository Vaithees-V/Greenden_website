# 🌿 Greenden

**Greenden** is a responsive plant and gardening website built using **HTML, Tailwind CSS, and JavaScript**. The project provides a clean and user-friendly interface for exploring plants and plant-related products across different screen sizes.

The website includes multiple pages such as **Home, Products, and Contact**, along with interactive JavaScript features for mobile navigation and product searching.

## ✨ Features

* 🌱 **Responsive Navigation Bar**

  * Desktop-friendly navigation menu
  * Mobile menu button for smaller screen sizes
  * Mobile menu displays **Home, Products, and Contact** pages

* 🪴 **Plant & Product Sections**

  * Attractive plant/product cards
  * Image-based product display
  * Clean and simple UI

* 🔍 **Responsive Product Search**

  * Search for plants and trees from the Products page
  * Displays relevant plant recommendations based on the user's typing
  * Provides a better user experience while searching for products

* 📱 **Fully Responsive Design**

  * Optimized for desktop, tablet, and mobile screens
  * Responsive layouts using Tailwind CSS

* 📄 **Multiple Pages**

  * Home
  * Products
  * Contact

* ⚡ **JavaScript Functionality**

  * Mobile navigation menu
  * Dynamic product search and recommendations

## 🛠️ Technologies Used

* **HTML5** – Website structure

## 📱 Responsive Navigation

Greenden includes a responsive navigation system.

On desktop screens, the navigation links are displayed normally.

On mobile screens, a **menu button** is displayed. Clicking the button reveals:

```text
Home
Products
Contact
```

The navigation is implemented using **JavaScript** in `script.js`.

## 🔍 Product Search & Recommendations

The **Products** page includes a responsive search feature.

Users can type the name of a plant or tree into the search box. The website dynamically filters and displays relevant products based on the user's input.

For example:

```text
User types: Rose

↓
Relevant plant recommendations are displayed
```

This functionality is implemented using **JavaScript** in `product.js`.
